# Agent Role Cards

这个目录存放 gagaToday 项目中不同 agent 的单独工作说明。

如果要开启另一个 agent 会话，请把对应角色文档作为它的首要任务说明，并要求它先阅读：

1. 根目录 `gagaToday_project_design_document.md`;
2. `docs/MVP_IMPLEMENTATION_PLAN.md`;
3. `docs/PROJECT_FRAMEWORK.md`;
4. `docs/AGENT_WORKFLOW.md`;
5. `docs/CONTENT_SCHEMA.md`;
6. 本目录中对应的角色文档。

## 通用本地产出规范

所有 agent 都应该把“工作记录”存到本地，方便主协调 agent 统一审核和合并。

批次命名：

```text
YYYYMMDD_简短任务名
```

每个批次至少包含：

```text
运行总结.md
```

推荐结构：

```text
docs/agent_runs/
  架构/
  游戏核心/
  前端/
  内容/
  NPC/
  课程/
  人工智能后端/
  内容流水线/
  餐馆导入/
  德国美食/
  德国探索/
  德国交通/
  质量测试/
```

`运行总结.md` 推荐格式：

```markdown
# 运行总结

## 任务

## 改动文件

## 产出文件

## 验证方式

## 未完成项

## 需要主协调 agent 处理
```

## 协作原则

- 每个 agent 只在自己的目录内工作。
- 需要跨目录时，先写说明，不直接大改。
- 所有成果都要说明改动文件、验证方式、未完成项。
- 用户或主协调 agent 负责最终整合。
