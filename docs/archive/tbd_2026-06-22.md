# gagaToday 下一步待办

更新时间：2026-06-21

## 0. 当前判断

项目方向已经确定：

> 用真实德国生活数据，构建一款慕尼黑 30 天留学生活模拟 RPG。  
> 第一阶段不是做完整大世界，而是先做可玩 MVP：生活、学习、预算、交通、餐饮、探索、NPC、AI 语言任务。

当前已经有：

- 新版项目设计文档；
- 多智能体工作文档；
- 慕尼黑基础地点 / 路线 / 对话 JSON；
- `frontend/src/core/` 游戏核心雏形；
- 欧元钱包和交易记录雏形；
- 一批美术原图和可用角色 / 场景素材。

当前还缺：

- 完整数据智能体体系；
- 可审核真实世界数据库；
- 第 1 天完整可玩闭环；
- 美术资产整理；
- 预算系统完整接入。

## 3. 第 1 天可玩闭环

目标：玩家能完整玩完游戏第 1 天。

### 3.1 第 1 天流程

```text
起床
→ 寄宿家庭早晨对话
→ 查看手机 / 任务
→ 从家去学校
→ 课堂自我介绍
→ 放学去面包店
→ 用德语买 Brötchen
→ 花费 €1.20
→ 回家
→ 回复父母消息
→ 状态结算
→ 保存进度
```
