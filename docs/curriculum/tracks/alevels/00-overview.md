## 1. 考试局选型:**Edexcel IAL(International A Level)**

### 1.1 选型理由(同前)

| 维度 | Edexcel IAL | CAIE(对比) | AQA / OCR(对比) |
|------|------------|-----------|----------------|
| **国际认可度** | 全球最广,170+ 国家 | 高,140+ 国家 | 主要英国本土 |
| **中国学生熟悉度** | 最高(雨中国高等指定) | 高 | 中 |
| **教材/真题丰富度** | 极丰富 | 丰富 | 一般 |
| **考试时间灵活性** | 1月 / 5-6月 / 10月 3 次 | 6月 / 11月 2 次 | 6月 1 次 |
| **重考政策** | 单元可单独重考 | 整卷重考 | 整卷重考 |
| **模块化** | IAS + IA2 拆分明确 | 整张 A-level | 整张 A-level |

**结论**:**Edexcel IAL**——全球可用、模块化、教材资源最多、中国学生最熟、错峰考试能补考。

### 1.2 IAL 的模块化结构

```
IAL(完整 A-level) = IAS(AS 部分) + IA2(A2 部分)
```

**重要命名更新(2026-06-21 修正)**:
- **2018 改革后** IAL Mathematics 单元名是 **Pure Mathematics 1-4 (P1-P4)**,不是 Core Mathematics C1-C4
- 单元 code:**WMA11, WMA12, WMA13, WMA14**(原 C1-C4 是 WMA01-04,**已弃用**)
- 类似地:Physics 是 **WPH11-16**,Chemistry **WCH11-16**,Biology **WBI11-16**
- 本文档所有 `c1` / `c2` 命名需要改为 `p1` / `p2`

### 1.3 重要事实:**Edexcel IAL 不提供 Further Mathematics**

- **Further Mathematics 在 Edexcel IAL 体系里没有**(只有 GCE 本土 A-level 提供,代码 9372)
- 中国学生要学"进阶数学" → 通常走:
  - **CAIE 体系的 Further Mathematics**(代码 9231/9609)
  - 或 Edexcel IAL Mathematics 选修 **Mechanics 2 / 3** 替代
- **本项目决定**:不强行"创造"Further Maths IAL,改为在路线文档里**推荐想学 FP 1/2/3 的学生选 CAIE 体系**
- 详细看 `routes/apply-to-germany.md`

## 4. 单元结构(以数学为例,使用真实 IAL 命名)

```
IAL Mathematics = IAS(3 papers) + IA2(2 papers)
├── IAS
│   ├── Pure Mathematics 1 (P1) [WMA11/01]   ← 实际 2018 改革后叫 P1,不是 C1
│   ├── Pure Mathematics 2 (P2) [WMA12/01]
│   └── Pure Mathematics 3 (P3) [WMA13/01]
└── IA2
    ├── Pure Mathematics 4 (P4) [WMA14/01]
    └── 1 个 Application Unit 选修(Statistics 1 / Mechanics 1)
       ├── Statistics 1 (S1) [WST01/01]
       └── Mechanics 1 (M1) [WME01/01]
```

每科都有自己的单元结构(P1-P4,或 P1-P6 / S1-S2 等),统一存到 `subjects/{subject}.md` 描述。

**重要**:本项目用 **WMA11-14** 代码,不用 WMA01-04(已弃用)。

## 5. KP 拆解的工作流(规范化)

### 5.1 整体流程

```
抓 Edexcel 官方 Specification (scripts/curriculum/fetch_edexcel_specs.py)
    ↓
把 Specification 切分到 topic(按官方 §X.Y 章节)
    ↓
每个 topic 喂给 LLM,生成 KP 列表(用 KP_SCHEMA.md 的 prompt 模板)
    ↓
LLM 输出 KP YAML,**所有 specification_ref 必填 + 必查证**
    ↓
自动检查(字段完整性 / ID 唯一 / source 存在)
    ↓
人工 review(用户/老师)+ past_paper_ref 必查证
    ↓
写入 tracks/alevels/knowledge-points/{subject}/{unit}-{topic}.md
    ↓
标记 review_status: reviewed
```

### 5.2 关键工具

- **scripts/curriculum/fetch_edexcel_specs.py** —— 抓 Edexcel 官方 specs
- **scripts/curriculum/validate_kp.py** —— 扫所有 KP,检查字段完整性
- **scripts/curriculum/coverage_report.py** —— 报告每科 KP 覆盖率(对比 spec topic 列表)
- **scripts/curriculum/diff_against_pmt.py** —— 对比 Physics & Maths Tutor 的 topic 列表,找漏

### 5.3 LLM 辅助的边界(再强调)

| LLM 能做 ✅ | LLM 不能做 ❌(必须人工查证) |
|------------|---------------------|
| 把 spec 段落拆成 KP 列表 | **specification_ref 章节号必须人工查证** |
| 写出 KP 的 Explanation | **past_paper_ref 出处必须人工查证** |
| 生成 Examples | 评估 difficulty(主观) |
| 关联 textbook_ref | 决定 exam_weight / exam_frequency(需要分析真题) |
| 检查 spec 字段完整性 | 关联游戏关卡设计 |

### 8.2 用户必须接受的现实
- **21 门全拆到 KP + past_paper 验证**:**需要几个月持续工作**,不是"一次写完"
- **过程中很多 KP 需要老师 review**(LLM 拆得不完全对)
- **建议分阶段做**:
  - Phase A1(已完成):骨架 + 1 个章节示例
  - Phase A2(下一步,1 周):P1 全部 6 主题拆完
  - Phase A3(2-3 周):Tier 1 主科 8 门各拆 1 单元
  - Phase A4(1-2 月):Tier 1 主科全部
  - Phase A5(3-6 月):Tier 2 副科 12 门
  - **持续**:新 spec / 新 past paper 时增量更新

### 8.3 严格方法论(从这次教训中)
- **禁止**:`[REVIEW_NEEDED]` 标记 = 没查证就写。这是错的。
- **强制**:每条 specification_ref 必查证,查不到的标 `pending_verification` 并放到 `knowledge-points/_pending/` 目录
- **强制**:每条 past_paper_ref 必查证(用题目 PDF + mark scheme)
- **强制**:每条 textbook_ref 必能点开(用户能直接访问)
