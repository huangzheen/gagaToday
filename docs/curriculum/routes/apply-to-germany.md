# 申请德国留学路线

> 三轨道整合:**德语(主线)+ 雅思 7.0+ + A-levels IAL(全科)**
> 这是项目的**唯一主路线**(按用户决策,2026-06-21)
> 版本: v1.0  ·  2026-06-21

---

## 1. 路线总览

### 1.1 目标画像

```yaml
profile:
  name: "中德班 / 雨中国高学生"
  starting_age: 15-16
  starting_level:
    chinese: 母语
    english: 雅思 5.0-5.5(中考 95+)
    german: 0 基础
  target:
    german: TestDaF TDN 4-5 (B2-C1)
    english_ielts: 每科 7.0+(4 项均 7.0+)
    alevels: 3-4 门 A*-A(申请用)
  university:
    tier_1: TU9 / 精英大学(Munich / Aachen / Heidelberg / 等等)
    tier_2: 其他公立大学
```

### 1.2 3 条轨道的关系

| 轨道 | 角色 | 优先级 | 考试时间 | 目标等级 |
|------|------|-------|---------|---------|
| **Deutsch 德语** | **主线**(申请硬门槛) | 🥇 P0 | 高二下 / 高三上 | TDN 4-5 |
| **IELTS 雅思** | **核心**(申请硬门槛) | 🥇 P0 | 高二下 | 4 项均 7.0+ |
| **A-levels** | **学术能力证明** | 🥈 P1 | 高三上 / 高三下 | 3-4 门 A*-A |

**注**:
- **德福 TDN 4 是德国大学最普遍要求**,TDN 5 是 TU9 / 精英大学常要求
- **雅思 7.0 是 TU9 / 精英大学英语授课项目普遍要求**(部分项目 6.5 即可,但 7.0 保险)
- **A-levels** 体现学术深度,德国大学(尤其精英 / TU9)对国际生**也认可 A-levels**

### 1.3 时间线(2 年)

```
9年级结束(中考毕业)
    ↓
10年级(高一) ─→  雅思 5.0 → 6.5 + A-levels IAS 3-4 门
    ↓
11年级(高二) ─→  德语 A1 → B1 + 雅思 6.5 → 7.0 + A-levels IA2
    ↓
11年级下(申请季) ─→  提交申请(德福 / 雅思 / A-levels 预估分)
    ↓
12年级(高三) ─→  拿到录取 + 办签证 + 入学
```

**2 年时间分配**(每周 15-20 小时总投入):
- 10 年级:**雅思 + A-levels 为主**(占 70%),德语 0-1 入门
- 11 年级:**德语 + 雅思 7.0 攻坚 + A-levels 收尾**(各 1/3)

## 2. 雅思路线(每科 7.0+)

### 2.1 目标
- **听说读写 4 项均 ≥ 7.0**
- "可以拿不到,但不能不学"——按 7.0+ 准备,允许部分项 6.5 但要尽量突破

### 2.2 阶段路径

| 阶段 | 周数 | 目标 | 重点 KP | 资源 |
|------|------|------|---------|------|
| **0. 摸底** | 1 | 测真实水平 | 全真模考(剑雅 16 Test 1) | 剑雅 4-19 |
| **1. 基础** | 6-8 | 词汇 + 语法 | 词汇 5000 + 基础语法 | AWL 词表 / Anki |
| **2. 强化** | 12-16 | 题型 + 技巧 | 4 项题型分别突破 | IELTS Liz / E2 IELTS |
| **3. 突破 7.0** | 6-8 | 评分标准对齐 | 评分标准 KP + 高难度话题 | 7.0+ 范文 / 模考 |
| **4. 模考** | 4-6 | 真题训练 | 剑雅 10-19 真题 8-12 套 | 剑雅官方 |

**总时长**:**30-40 周**(10-12 个月)

### 2.3 重点 KP(本项目 7.0 突破关键)

**Listening**:
- KP #7 同义替换识别
- KP #8 观点态度识别
- KP #10 学术词汇储备

**Reading**:
- KP #14 同义替换识别
- KP #15 长难句分析
- KP #17 生词处理策略

**Writing**:
- Task 2 4 大题型 + 立场明确
- 复杂从句 + 同义替换
- 7.0+ 范文模仿(每周 2-3 篇)

**Speaking**:
- Part 1 30 话题全覆盖
- Part 2 4 大类(人物/事件/地点/物品)各 5 卡
- Part 3 抽象话题深度讨论

### 2.4 真题使用计划
- **剑雅 4-9**:基础训练(每天 1 Section 听力 / 1 篇阅读)
- **剑雅 10-13**:强化(每周 2 套)
- **剑雅 14-19**:模考(每周 1 套,严格限时)
- **剑雅 17-19**:考前 4 周冲刺(每周 1 套 + 精讲)

## 3. A-levels 路线(Edexcel IAL 全科)

### 3.1 目标
- **3-4 门主科拿 A*-A**
- **25 门副科建立完整知识库**(供查阅 / 备选)
- 不是"全精",是"主精 + 副全"

### 3.2 选科建议(3-4 门主科)

| 类别 | 推荐 | 理由 |
|------|------|------|
| **必修:数学** | Mathematics IAL | 几乎所有专业都需要;中国学生强项 |
| **必修:进阶数学** | Further Mathematics IAL | 数学 / 工程 / 物理必备 |
| **强烈推荐:物理** | Physics IAL | 工程 / 自然科学专业必备 |
| **强烈推荐:化学** | Chemistry IAL | 医学 / 生物 / 化学 / 工程 |
| **可选:经济** | Economics IAL | 经济 / 商科方向 |
| **可选:生物** | Biology IAL | 医学 / 生物方向 |
| **可选:计算机** | Computer Science IAL | CS / 工程方向 |

**典型组合**(中国学生):
- **理工**:`数学 + 进阶 + 物理 + 化学`(或 `+ 经济`)
- **工程**:`数学 + 进阶 + 物理 + 计算机`
- **经济/商**:`数学 + 进阶 + 经济 + 商务`
- **医学/生物**:`数学 + 化学 + 生物 + 物理`

### 3.3 阶段路径(2 年 IAS + IA2)

| 阶段 | 时间 | 目标 | 内容 |
|------|------|------|------|
| **0. 基础(可选)** | 暑假 4 周 | 补 IGCSE 基础 | IGCSE Mathematics + 1 门理科 |
| **1. IAS** | 10 年级(高一)全年 | 3-4 门 IAS 完成 | C1/C2/C3 (数学) + P1/P2 (物理) + ... |
| **2. IA2** | 11 年级(高二)全年 | 3-4 门 IA2 完成 | C4/M1/S1 (数学) + P3-P6 (物理) + ... |
| **3. 模考** | 11 年级下(申请前) | 真题训练 | Past papers 2018-2024 |

**考试时间安排**:
- 1 月:数学 + 物理 + 1 门(若时间允许)
- 5-6 月:剩余 IAS 单元(主考期)
- 10 月:IA2 单元 + 重考

### 3.4 KP 学习路径

```
IGCSE 基础(可选,4 周)
    ↓
IAL IAS 3 单元 / 科
    ↓
IAL IA2 2 单元 / 科(其中 1 个 application 选修)
    ↓
A* 突破(模考 + 错题)
```

**每门科目的 KP 学习量**(数学 IAL 全部 5 单元):
- C1: ~60 KP
- C2: ~70 KP
- C3: ~70 KP
- C4: ~70 KP
- S1 或 M1(选修):~50 KP
- **总计**:~320 KP(数学 IAL 全部)

**3-4 门主科**:**1000-1300 KP**

**8 门 Tier 1 全精**:**2500-3000 KP**

**33 门全 KP 索引(目标)**:~10000 KP

## 5. 游戏化整合(三轨道)

### 5.1 关卡类型(3 种)

| 类型 | 适用轨道 | 形式 | 例子 |
|------|---------|------|------|
| **对话关卡** | 德语 + 雅思口语 | 玩家与 NPC 语音对话 | 在柏林咖啡馆点咖啡 / 在伦敦机场问路 |
| **题库关卡** | A-levels + 雅思(听/读/写) | NPC 出题,玩家答题 | 数学:NPC 出"解 x² - 5x + 6 = 0",玩家回答;雅思听力:播放录音,玩家填空 |
| **概念讲解关卡** | A-levels(理论部分) | 玩家解锁概念卡片 | 解锁"二次公式"卡片,带讲解 + 例子 + 真题 |

### 5.2 三轨道的游戏化设计

#### 德语(主线)
- 沿用现有"走遍德国"地图
- 16 州 60-100 关
- 重点:对话关卡 + 文化卡 + 反馈卡

#### 雅思(辅助)
- "闯荡英美"独立地图
- 4 大关卡群(听说读写),每关卡群 10-20 关
- 重点:题型训练 + 真题模拟
- **不强制解锁**(用户主修德语时,雅思作支线)

#### A-levels(辅助)
- "学术塔"独立关卡群
- 每门学科一塔,每 unit 一层
- 重点:题库关卡 + 概念卡
- **不强制解锁**

### 5.4 跨轨道联动
- 雅思口语 P2 卡片 → 复用德语对话引擎
- A-levels 数学 KP → 嵌入德语对话(用德语讨论数学)
- 三轨道都涉及"语法错误" → 统一错题本

### 7.1 雅思
- **必备**:剑桥雅思真题 4-19(14 本)

  - Znotes(学生笔记)

- **必备**:Menschen A1/A2 + Aspekte B1+/B2 + Mit Erfolg zum TestDaF

## 9. 风险与对策

| 风险 | 影响 | 对策 |
|------|------|------|
| 雅思 7.0 拿不到(口语 6.5 顶) | 影响英语授课项目 | 主要申请德语授课项目 + 英语项目作备选 |
| 德福 TDN 4 拿不到 | 影响德国入学 | 补考 / 选对德语要求低的学校 / 先读语言班 |
| A-levels IA2 拿不到 A* | 影响精英大学 | 选普通要求大学 + 进去后转专业 |
| 三轨道时间冲突 | 进度慢 | 优先级:德语 > 雅思 > A-levels,主精 3-4 门 |
